📖 如何获取 Cookie

  1. 打开目标网站（如豆包、文心一言、Kimi 等）并登录
  2. 按 F12 打开浏览器开发者工具
  3. 切换到 Application（Chrome）或 Storage（Firefox）选项卡
  4. 在左侧找到 Cookies 并点击当前域名
  5. 复制所有 Cookie 值（或复制关键的 session_id、token 等）
  6. 将 Cookie 粘贴到上方的 API Key 输入框中
提示：Cookie 模式不需要 API Base URL，但需要填写有效的模型名称
