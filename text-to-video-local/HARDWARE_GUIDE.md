# 硬件配置详细指南

本文档详细介绍部署文生视频程序所需的硬件配置，分为三个等级满足不同需求。

## 硬件配置总览

| 配置等级 | 适用模型 | GPU | 显存 | 预算范围 | 生成速度* |
|---------|---------|-----|------|---------|----------|
| **入门级** | AnimateDiff, ModelScope | RTX 4080/4090 | 16-24GB | ¥8,000-18,000 | 2-5 分钟 |
| **专业级** | CogVideoX-5B | 2×RTX 4090/2×A100 | 48-160GB | ¥30,000-150,000 | 1-3 分钟 |

*生成速度指生成 16 帧 256×256 视频的参考时间

## 注意事项

### 硬件兼容性

1. **GPU 支持**: 必须使用 NVIDIA GPU（CUDA 生态）
2. **PCIe 通道**: 多卡配置需要足够的 PCIe 通道数
3. **电源功率**: 确保电源功率充足，留有 20% 余量
4. **散热系统**: 高性能 GPU 发热量大，需要良好散热

### 软件环境

- **操作系统**: 推荐 Ubuntu 20.04/22.04 LTS
- **CUDA 版本**: 11.8 或 12.1+
- **显卡驱动**: 535.104.05 或更新
- **Python 版本**: 3.10 或 3.11

### 显存优化

如果显存不足，可使用以下优化：

```bash
# 使用半精度（float16）
--dtype float16

# 启用模型 CPU offload
--cpu-offload

# 降低分辨率
--height 256 --width 256

# 减少帧数
--num-frames 8

# 使用量化版本（如果可用）
--quantize int8
```

### 功耗管理

- RTX 4090 TDP: 450W
- A100 40GB TDP: 250W
- A100 80GB TDP: 300W

建议配置 UPS 不间断电源，防止生成过程中断电。
