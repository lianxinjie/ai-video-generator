## 一、已集成的硬件检测功能

### 1.1 资源监控模块 (monitor.py)

**功能**: 实时监控硬件资源使用情况

**检测项目**:
- ✅ GPU 显存使用率
- ✅ GPU 温度
- ✅ CPU 使用率
- ✅ 系统内存使用率
- ✅ 磁盘使用率

**智能功能**:
- ✅ 自动检测 GPU 是否存在
- ✅ 自动识别 GPU 型号和显存大小
- ✅ 阈值告警（超过阈值自动暂停）
- ✅ 安全状态判定

**代码示例**:
```python
# 初始化监控器
monitor = ResourceMonitor(
    gpu_memory_threshold=75.0,    # GPU 显存阈值 75%
    gpu_temp_threshold=80.0,      # GPU 温度阈值 80°C
    cpu_threshold=85.0,           # CPU 使用率阈值 85%
    memory_threshold=80.0,        # 内存阈值 80%
    disk_threshold=90.0           # 磁盘阈值 90%
)

# 自动检测 GPU
if self.has_gpu:
    logger.info(f"检测到 GPU: {torch.cuda.get_device_name(0)}")
    logger.info(f"  - 显存：{torch.cuda.get_device_properties(0).total_memory / 1024**2:.0f} MB")
```

**限制**:
- ⚠️ 需要安装 `psutil` 库
- ⚠️ 需要安装 `torch` 才能监控 GPU
- ⚠️ 仅适用于 Linux/Windows，不支持 macOS GPU

**功能**: 显示不同硬件配置适合的模式

| **协同模式** | 任意配置 | 任意配置 |
