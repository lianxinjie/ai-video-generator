# Web 主页面场景查看与编辑集成

## 🎉 功能概述

现在用户可以直接在 Web 主页面进行**智能场景分析**和**交互式编辑**，无需跳转页面！

---

## ✨ 新增功能

### 1. 智能场景分析按钮

在主页面表单底部，新增了两个按钮：

- **🔍 先分析场景**：分析提示词并切分场景
- **🎬 直接生成视频**：跳过分析直接生成（原有功能）

### 2. 场景查看面板

点击"先分析场景"后，页面下方会显示：

- **场景列表**：所有场景的卡片列表
- **场景汇总**：总场景数、总时长
- **工具栏**：添加场景、导出、导入、确认生成

### 3. 交互式编辑

- **点击卡片**：进入编辑模式
- **修改提示词**：调整场景描述
- **调整时长**：0.5 秒为最小单位
- **添加场景**：在末尾添加新场景
- **删除场景**：移除不需要的场景

### 4. 导出/导入功能

- **导出场景**：保存为 JSON 文件
- **导入场景**：从 JSON 文件加载配置

### 5. 确认后生成

编辑完成后，点击"✓ 确认并开始生成"：
- 保存场景配置
- 提交视频生成任务
- 显示进度条
- 生成完成后提供下载

## 🎯 使用流程

### 方式 1：先分析后生成（推荐）

```
1. 访问 http://localhost:5000
2. 输入提示词："勇敢的骑士在古老城堡中与巨龙战斗"
3. 选择模式：collaborative / optimized
4. 设置时长：10 秒
5. 点击"🔍 先分析场景"
6. 等待分析完成（显示 5 个场景）
7. 查看场景列表：
   - 场景 01: 骑士站在城堡前（5.0 秒）
   - 场景 02: 城堡内部大厅（4.5 秒）
   - 场景 03: 激烈战斗场面（6.0 秒）
   - ...
8. 点击场景卡片进行编辑
9. 修改不满意的场景
10. 点击"✓ 确认并开始生成"
11. 等待视频生成完成
12. 下载视频
```

### 方式 2：直接生成（保持原有流程）

```
1. 访问 http://localhost:5000
2. 输入提示词和设置参数
3. 点击"🎬 直接生成视频"
4. 等待生成完成
```

## 🔌 API 集成

### 场景分析流程

```javascript
// 1. 分析场景
POST /api/analyze
Body: { prompt: "...", duration: 10, mode: "auto" }
Response: { scenes: [...], total_scenes: 5 }

// 2. 编辑场景（前端完成）
- 用户点击卡片编辑
- 修改 prompt/duration
- 前端更新场景数组

// 3. 保存并生成
POST /api/scenes (保存场景)
POST /api/generate (开始生成视频)
```

### 前端核心函数

```javascript
// 分析场景
async function analyzeScenes() {
    const response = await fetch('/api/analyze', {
        method: 'POST',
        body: formData
    });
    const data = await response.json();
    currentScenes = data.scenes;
    displayScenesPanel();
}

// 显示场景面板
function displayScenesPanel() {
    // 渲染场景卡片
    // 显示编辑表单
}

// 确认并生成
async function confirmAndGenerate() {
    await fetch('/api/scenes', {
        method: 'POST',
        body: JSON.stringify({scenes: currentScenes})
    });
    await fetch('/api/generate', {
        method: 'POST',
        body: formData
    });
}
```

## 💡 使用技巧

### 1. 高效编辑

- **批量修改**：依次点击多个场景进行编辑
- **快速添加**：点击"+ 添加场景"快速插入
- **删除确认**：删除前会弹窗确认

### 2. 场景管理

- **导出备份**：编辑完成后导出 JSON 备份
- **导入复用**：导入之前的成功场景配置
- **版本控制**：导出不同版本对比

### 3. 最佳实践

- **先分析**：让 AI 先切分，再手动微调
- **保持连贯**：场景之间逻辑连贯
- **合理时长**：3-12 秒/场景为宜

## 🔧 技术实现

### HTML 结构

```html
<!-- 场景面板 -->
<div class="scenes-panel" id="scenesPanel">
    <h3>🎬 智能场景分析结果</h3>
    
    <!-- 工具栏 -->
    <div class="scenes-toolbar">
        <div id="scenesSummary">共 X 个场景</div>
        <button onclick="addNewScene()">+ 添加场景</button>
    </div>
    
    <!-- 场景列表 -->
    <div id="scenesList" class="scene-list"></div>
    
    <!-- 操作按钮 -->
    <div class="scenes-actions">
        <button onclick="exportScenes()">📥 导出</button>
        <button onclick="importScenes()">📤 导入</button>
        <button onclick="confirmAndGenerate()">✓ 确认生成</button>
    </div>
</div>
```

### CSS 样式

- `.scenes-panel`: 场景面板容器
- `.scene-card`: 场景卡片
- `.scene-card.editing`: 编辑模式
- `.scene-edit-form`: 编辑表单

### JavaScript 函数

- `analyzeScenes()`: 分析场景
- `displayScenesPanel()`: 显示场景面板
- `toggleSceneEdit(index)`: 切换编辑模式
- `saveSceneEdit(index)`: 保存编辑
- `addNewScene()`: 添加场景
- `deleteScene(index)`: 删除场景
- `confirmAndGenerate()`: 确认并生成
